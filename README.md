# Temporizador

Actualizaciones de la app **Temporizador** (temporizador, letras de cantos, Biblia y salidas a pantallas).

Las computadoras que tienen la app instalada descargan solas las versiones nuevas desde la sección **Releases** de este repositorio.

Para instalarla por primera vez, descarga `Temporizador-Instalador-x.y.z.exe` de la última versión en **Releases**.
